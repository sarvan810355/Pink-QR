chime.wav is a synthesized placeholder — a soft two-note bell "ting"
generated by scripts/generate_chime.py (no real recording tool was
available when this project was built). It's fine to ship as-is, but if
you want a nicer/more polished sound, drop a replacement "chime.wav" here
(keep it short, under ~1s, and soft — a light bell/sparkle "ting", not a
harsh beep) — lib/services/feedback_service.dart just plays whatever file
is at this path.

FeedbackService fails silently if the file is missing, so the app still
runs without it — scan success just falls back to haptic-only.
